# NewerTab

NewerTab is a new design for the chrome://newtab page. NewerTab has a search engine selector, a search bar, and multiple movable widgets with customizable themes! It is a website built in HTML, JS and CSS. I do not like the default chrome new tab and it's lack of features and this inspired me to make a custom one. You can try it at https://newertab.vercel.app. You can also locally run it by cloning the GitHub repository and using the HTML files but you will need an HTTP server for specific API's, like Spotify. In the future, I plan to make a chrome extension for my custom new tab. I will include the current code and even more features, including tab management and CPU/memory usage information.

You can try it at [newertab.vercel.app](https://newertab.vercel.app/).

The source of the project is in [`/src`](./src). Id you wish to run it locally, you will need to run a HTTP server because of the API's it uses.
